# Задачи и встречи

Сайт, где можно голосом или текстом поставить задачу, встречу или напоминание и посмотреть, что уже есть в календаре.

## Как запустить у себя

```bash
python -m pip install -r requirements.txt
python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

Откройте http://127.0.0.1:8000

Ключи лежат в `.env` (образец — `.env.example`). Нажмите на кружок и говорите: запись остановится, когда замолчите. Строка справа открывает карточку.

## Выкладка на Vercel

Ключи уже лежат в проекте, в кабинет Vercel их вставлять не нужно.

```bash
npx vercel login
npx vercel --prod
```

На бесплатном плане база живёт в `/tmp`: при холодном старте подгружается архив из CSV. Новые записи могут пропасть, когда функция заснёт. Для постоянной базы нужен Postgres.

## GitHub

Репозиторий можно создать пустым на github.com и прислать ссылку — тогда его привяжут к этой папке и зальют код. Либо залить самим:

```bash
git init
git add .
git commit -m "Первая версия планировщика"
git branch -M main
git remote add origin https://github.com/ВАШ_ЛОГИН/ВАШ_РЕПО.git
git push -u origin main
```

`.env` в GitHub не попадает.
